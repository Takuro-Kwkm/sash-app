# リプラス候補のガラス選択順 V13

営業表示を「ガラス種類 → ガラス種（透明・型板・フロスト・乳白）→ Low-E詳細 → 追加機能」に揃える。居室・TW・EW・浴室仕様の4候補を変更し、アタッチ枠2仕様・汎用カットモールは既存の共通サッシ表示順と固定参照をそのまま保持する。

透明／型板などはガラス種類に依存し、Low-E詳細・追加機能の未選択時にも選べる。Low-E詳細は種類と見え方を親として持ち、追加機能は種類・見え方・詳細を親として持つ。既存Evidenceで確認された乳白と安全合わせ乳白の対応を、後段の追加機能のSelectorで判定する。乳白を選ぶと不適合な追加機能が消え、乳白から透明・型板・フロストに変えると安全合わせ乳白が消える。適合する詳細と追加機能は保持する。Low-E詳細の解除時は先に選んだ見え方を保持し、ガラス種類の適用を失う窓種変更では関連項目を解除する。単一候補の既存自動選択は維持する。

販売順と依存方向の修正であり、公式カタログの選択肢・組合せのメーカー保証、製作可否、価格、BOM、発注コードを新たに確定しない。ガラス項目の既存必須・要確認区分、数量・価格HOLD、公式寸法ルールを保持する。元資料のメーカー表とEvidenceは変更せず、4冊の `14_UI選択契約` のみに変更の意味・依存・Selectorを記録する。

共通Runtime、Global Flow Engine、動的UI、Output Engineを変更せず、候補データだけで実装する。V12の内はめ部材／両カバー色の非表示、内部連動、寸法の最後への配置、採寸／仕上がり寸法の併記を維持する。
