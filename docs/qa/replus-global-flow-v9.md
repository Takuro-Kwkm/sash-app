# リプラス住宅用：グローバルセレクションフロー V9

両カバーの色をサッシ本体色から決定する。アングルカバーはガラスの直後、室外化粧カバーはその次に配置し、現場採寸・製品寸法は最後にまとめる。今回の色連動はユーザー承認されたアプリ運用方針であり、メーカーの同色必須規則として登録しない。

ダスクグレー等、原本のカバーに対応色がない場合は別色へ置換しない。対応部材の確認を残す。木製窓枠・ケーシングは別部材として保持する。

既存のアングルカバーOPは専用項目へ移動し、古い保存からの明示Migrationを保持。他の選択を巻き込んで削除しない。条件変更によって無効になった項目は解除し、画面に理由と再選択案内を表示する。
