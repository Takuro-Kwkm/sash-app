The connected scope is a **read-only primary catalogue audit**, executed by the
existing central `scripts/production-work.py` and immutable v2 journal. It does
not admit Source adoption, Product Master changes, Human Adoption, Formal save,
Runtime/UI integration or release. Other pending products remain fail closed.

Resolve `サーモスⅡHの最新版差分調査` through the acquired Current
`scripts/architecture-work.py`. This explicitly selects `SOURCE_AUDIT_VERIFIED`.
The retained central `確認/current-state` route selects `CURRENT_ADOPTED_ONLY`;
do not treat that route as latest-manufacturer discovery. The host hands the
user's latest comparison scope to the explicit audit route. Shared router,
Authority semantics, DAG, Resume, Formal storage and CI bridge are unchanged.

Acquire Current central/native branches, complete tree/blob identities, live
Information Source Manifest and its bootstrap requests, native Registry,
runtime manifest, authoring, old/new full PDFs, source metadata and the rendered
official current catalogue locator. Freeze every input byte hash. The candidate
remains `NEW_CANDIDATE / CANDIDATE`; filenames and the stored profile never prove
that a future source is latest. A changed edition/profile requires a successor.

`prepare-catalog-change-audit.py` takes host captures and produces the native
Workflow/spec. Run it and the shared runner with Python providing openpyxl 3.1.5
and pypdfium2 5.13.0. The worker verifies full text/page scope, a source-bound
rendered comparison, reviewed non-price/visual differences, nine catalogue
responsibility sections, native sheet identities, formula errors and exact
Formal/Runtime/Evidence preservation. Missing review, changed bytes or another
product blocks by name. Storage and checkpoint readback use the shared engine.

The 2026-10-07 comparison is IS6600 (2026-04 / May price edition) to IS9000
(2026-09 / October price edition), 360 pages each. `SER-LIX-SAMOS2H/review.json`
contains AI-reviewed findings and exact scope limits. The current `v0.9-R4`
authoring bytes match the freshly fetched live Formal manifest. PDF inputs are
local Drive mirror bytes, bound to connected identity/size and the rendered
official edition; cloud PDF binary readback is **NOT_VERIFIED** after the streamed
download reference returned HTTP 403. Technical/product web-source revisions
are outside this primary price-catalogue audit. Neither detector counts nor
completed audit gates mean that the identified manufacturer facts are adopted.
